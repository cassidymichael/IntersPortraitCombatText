# Inter's Portrait Combat Text

Adds unit frame's portrait combat text on WoW: Forever. Damage, heals, dodges, etc. Designed for players who use custom unit frames which don't have portrait combat text, or which don't have all the settings they want.

This addon creates movable areas for the combat text to appear (for self, for target, for pet), intended to be dragged over your setup's portraits, or anywhere really.

## Features

- Text for you, your target and your pet.
- Font options (the game's, or any from SharedMedia), size, outline, shadow, opacity.
- Critical hit variable size.
- Duration for each event to be shown.
- Choose what events show: damage, heals, misses and blocks, mana gains. Edit colours for each, or by damage type.
- Hide small amounts (e.g. damage taken under 100 can be hidden).
- Shorten number formats options (e.g. 1,234 becomes 1.2k).
- Preview and layout modes.
- Profile support and export/import.
- and more. This is a super basic addon, if you want any other features, just leave a comment and ask.

## Usage

`/pct` or the minimap button opens the options.

`/pct lock` unlocks or locks: drag a box to move it.

`/pct preview` toggles on and off the preview mode.

`/ipct` also works in place of `/pct`
